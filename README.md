# 🐍 Neon Snake

A retro-inspired Snake game with a dark neon aesthetic, built in vanilla JavaScript.

## Features

✨ **Dark Neon Theme** — Vibrant neon colors on a dark background  
⚡ **Speed Mode** — Toggle between normal and fast gameplay  
📊 **Real-Time Score** — Live score, high score, and length display  
🎮 **Responsive Controls** — Arrow keys, WASD, or touch swipe  
💾 **High Score Persistence** — Your best score is saved locally  
✨ **Particle Effects** — Visual feedback when eating food  
⏸ **Pause/Resume** — Press P to pause the game  

## Controls

| Key | Action |
|-----|--------|
| **Arrow Keys** or **WASD** | Move the snake |
| **Space** or **Enter** | Start game / Resume from pause |
| **P** | Pause / Resume |
| **F** | Toggle speed mode |
| **⚡ Fast Button** | Toggle speed mode (UI) |

## How to Play

1. **Start** — Press any arrow key, WASD, or click the START button
2. **Move** — Use arrow keys or WASD to control the snake
3. **Eat** — Move the head to the glowing pink food to grow
4. **Survive** — Avoid walls and your own tail
5. **Score** — Each food eaten = 10 points

## Installation

Simply open `index.html` in any modern web browser. No build process required—everything is self-contained in a single file.

```bash
git clone https://github.com/cheunjm/snake.git
cd snake
# Open index.html in your browser
open index.html  # macOS
start index.html # Windows
```

## Technical Details

- **Single File** — All CSS and JavaScript inlined in `index.html`
- **Vanilla JavaScript** — No dependencies
- **Canvas Rendering** — Hardware-accelerated graphics
- **Responsive** — Works on desktop and mobile devices
- **LocalStorage** — High score saved between sessions

## Browser Support

Works on all modern browsers supporting:
- HTML5 Canvas
- ES6 JavaScript
- LocalStorage API
- Touch events (for mobile)

## Design Inspiration

Dark neon aesthetic inspired by retro arcade games with bright, glowing colors on a dark background for that classic cyberpunk feel.
